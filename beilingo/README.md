# 龟虽寿 · 古诗背诵练习

原生 HTML、CSS 和 ES modules 实现的四阶段背诗练习，不依赖框架或构建工具。

## 启动

在仓库根目录运行：

```sh
python -m http.server 8000
```

然后打开 <http://localhost:8000/beilingo/>。也可以在 WebStorm 使用内置服务器，或在 VS Code 使用 Live Server。不要直接双击 `index.html`，浏览器会限制本地 ES modules。

## 学习流程

四个阶段依次为感知（整首诗逐句跟读）、理解（词义选择、根据词义选择诗句）、字形（拼音辨字）和默写（诗句默写、整首诗排序）。第一阶段每课按全诗顺序练习 14 句，每句显示拼音并自动播放；学生跟读后点击“下一句”继续。第二至第四阶段每课覆盖对应阶段题库中的全部题目；第二阶段第二课另含根据词义选择对应诗句的练习。题目顺序随机，错题会在本课队尾最多重考 3 次。各阶段课程数量可在 `js/config.js` 的 `LESSONS_PER_SECTION` 字典中按阶段编号设置。课程按顺序解锁，全部完成阶段后按设定间隔解锁下一阶段。答题状态和阶段进度保存在浏览器 `localStorage` 中。

## 调整参数与验证倒计时

在 `js/config.js` 调整 `SECTION_UNLOCK_DELAY_MS`，默认值为 1 小时。例如设为 `10000` 可用 10 秒验证。完成阶段 1 的全部课程后，阶段 2 会显示倒计时；等待约 10 秒后，阶段卡片会自动刷新为可进入状态。其他课程数量、抽题配额、复习间隔和存档 key 也集中在同一文件。

若需重新从头验收，可在浏览器开发者工具的 Application/Storage 面板删除 `poem_app_state_gsz`。
