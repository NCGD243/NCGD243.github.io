你是一个语文题库生成器。请依据**统编版初中语文教材**中指定古诗的课文内容、课下注释、课后练习，以及中考语文对该诗的常见考查方式，自行确定全诗诗句、重点字词、易错字和默写考点，生成严格符合下方 schema 的 exercise.json。不要依赖外部 poem.json。除“诗文范围”外，本指令的编码格式、字段结构、题量、lesson 组织、shuffle 规则均不得改动。

# 一、诗文范围

本指令针对的诗为：陶渊明《饮酒》（其五）。
全诗共 5 联（10 句）。以统编版教材通行版本为准。

（若换诗，只需替换本节的诗题、作者、联数；其余规则不变。）

# 二、输出 schema（必须与参考 exercise.json 完全一致）

顶层：
{
  "sections": {
    "s1": { "name": "感知", "lessons": [ ... ] },
    "s2": { "name": "理解", "lessons": [ ... ] },
    "s3": { "name": "字形", "lessons": [ ... ] },
    "s4": { "name": "默写", "lessons": [ ... ] }
  }
}

注意：每个 section 对象必须包含 "name" 字段，取值固定为：s1="感知"，s2="理解"，s3="字形"，s4="默写"。不得省略。

每个 lesson：
{ "name": "第X课", "id": "s{节号}l{课号}", "shuffle": true|false, "questions": [ ... ] }

每道题字段及顺序：
- id：字符串，"s{节号}l{课号}q{题号}"，题号从 1 连续编号
- type："read" | "option" | "order" | "spell"
- covered：二维数组，每个子数组为 [couplet_index, line_index]，couplet_index 从 1 开始，line_index 为 1 或 2
- prompt：字符串
- pinyinInfo：仅 read 和需要拼音的 spell 题出现，格式 {"show": true|false, "pinyin": "..."}；option 与 order 不出现此字段
- otherInfo：按题型：
  - read：{"line": "该句原文"}
  - option：{"content": "题干", "options": ["A","B","C","D"], "answer": [正确索引]}
  - order：{"lines": ["打乱后的句子", ...]}
  - spell：{"content": "含______或__的句子", "answer": "填写内容"}

通用编码规则（与参考文件一致，不得改动）：
- option 的 options 长度必须为 4，answer 为数组（即使唯一正确也写 [索引]）。
- order 题的 lines 必须打乱，不得按原诗顺序给出。
- spell 题中，s3 单字填空用 “__”，s4 整句/整联填空用 “______”。
- 输出必须是合法 JSON，不要注释，不要 markdown 代码块外的多余文字，只输出 JSON 本身。
- 拼音必须带声调且准确。

# 三、选择题干扰项差异化要求（适用于 s2l1 和 s2l2）

这是硬性要求，生成后必须逐题检查：

1. 四个选项之间不能是近义改写或包含关系。例如正确项是“车马的喧嚣”，干扰项不能再出现“车子的喧闹”“喧闹的车马”这类同义变体；也不能出现“喧嚣”与“车马喧嚣”这种包含关系。
2. 正确项与每个干扰项必须在**语义类别**上有明确区别。干扰项应分别来自不同角度，例如：字面误解、古今异义误读、张冠李戴（把别句的意思安到本句）、望文生义、程度/对象错位等。
3. 干扰项不能“一眼假”：不能出现与诗歌语境完全无关、明显荒谬的选项（如“一种古代乐器”“一种水生动物”这类与上下文毫无关联的凑数项）。干扰项应看似合理、但经辨析可排除。
4. 四个选项长度、语气尽量接近，避免正确项因表述最完整、最文雅而“露馅”。
5. 同一题内四个选项不得有两个意思相同或相近；不同题之间可以复用干扰思路，但不要复用完全相同的选项文字。
6. 选诗句题（s2l2 的“选诗句”）：四个选项必须是四句不同的诗句，干扰诗句应来自本诗其他联或同作者/同题材的常见诗句，不能是正确句的改写或拼接。
7. 选意思题（s2l2 的“选意思”）：四个释义要分别对应不同的理解偏差，不能有两个选项只是措辞不同而意思相同。

# 四、各 section 结构（与参考文件完全一致）

## s1 感知
- section 对象为：{ "name": "感知", "lessons": [ ... ] }
- lessons 数组含 1 课：name="第1课"，id="s1l1"，shuffle=false。
- 共 10 题，type 全部 read，按原诗顺序覆盖 5 联每一句（第1联上句→第1联下句→…→第5联下句）。
- 每题 covered 仅含当前这一句的位置。
- pinyinInfo.show=true，pinyin 为该句正确拼音（带声调）。
- prompt="跟读"，otherInfo.line=该句原文。

## s2 理解
- section 对象为：{ "name": "理解", "lessons": [ ... ] }
- lessons 数组含 3 课。

### s2l1
- name="第1课"，id="s2l1"，shuffle=true。
- 共 10 题，type 全部 option，prompt="选词义"。
- 依据教材课下注释和中考常考实词，选取 10 个重点字词，每个词一题，覆盖不同联，不得重复。
- content 格式：““X”的意思是？”
- options 为 4 个释义，1 个正确、3 个干扰；answer 为正确索引。干扰项必须遵守第三节“选择题干扰项差异化要求”。
- covered 为该词所在句的位置。

### s2l2
- name="第2课"，id="s2l2"，shuffle=true。
- 共 10 题，type 全部 option。
- 5 联每联 2 题：1 题 prompt="选诗句"（给白话翻译选原句），1 题 prompt="选意思"（给原句选释义）。
- 选诗句题：content 为该联的白话翻译；options 为 4 句不同诗句（1 句正确，3 句干扰）；answer 指向正确诗句。
- 选意思题：content 为““本联某句”的意思是？”；options 为 4 个释义；answer 指向正确释义。
- covered 为该题对应句的位置。
- 白话翻译需依据教材和通行教参，准确通顺。
- 所有 option 题必须遵守第三节“选择题干扰项差异化要求”。

### s2l3
- name="第3课"，id="s2l3"，shuffle=false。
- 共 10 题，type 全部 order，prompt="排序"。
- 前 5 题：每联单独排序（两句打乱），covered 含该联两句。
- 接着 4 题：相邻两联合并排序（联1+联2、联2+联3、联3+联4、联4+联5），covered 含涉及四句。
- 最后 1 题：全诗 10 句排序，covered 含全部句子。
- 所有 lines 必须打乱。

## s3 字形
- section 对象为：{ "name": "字形", "lessons": [ ... ] }
- lessons 数组含 1 课：name="第1课"，id="s3l1"，shuffle=true。
- 共 10 题，type 全部 spell，prompt="填写句子"。
- 依据教材中该诗的易错字、形近字、重点字选取 10 个，每题挖 1 个字，覆盖不同联，不得重复。
- pinyinInfo.show=true，pinyin 为该字拼音（带声调）。
- otherInfo.content 为含 “__” 的该句，answer 为该字。
- covered 为该字所在句的位置。

## s4 默写
- section 对象为：{ "name": "默写", "lessons": [ ... ] }
- lessons 数组含 2 课。

### s4l1
- name="第1课"，id="s4l1"，shuffle=true。
- 共 10 题，type 全部 spell，prompt="填写句子"。
- 每联 2 题：一题给上句填下句，一题给下句填上句。
- pinyinInfo.show=false。
- content 中用 “______” 表示空缺，answer 为完整一句。
- covered 为被填写句的位置。

### s4l2
- name="第2课"，id="s4l2"，shuffle=true。
- 共 5 题，type 全部 spell，prompt="填写句子"。
- 第 1~4 题给出第 k 联，填写第 k+1 联整联两句；第 5 题给出第 4 联，填写第 5 联（确保最后一联被覆盖）。
- pinyinInfo.show=false。
- content 格式：“上一联。______”
- answer 为需填写的完整一联（两句，保留原标点）。
- covered 为 answer 对应两句的位置。

# 五、自检

1. 顶层 sections 下 s1~s4 每个对象都必须有 "name" 字段，取值分别为 "感知""理解""字形""默写"。
2. lesson 的 name/id/shuffle、题量、prompt 文字、字段名与顺序均与参考 exercise.json 一致。
3. 只有诗句原文、拼音、词义、易错字、白话翻译、默写句随诗变化。
4. covered 合法，id 连续。
5. option 的 options 为 4 项，answer 为数组。
6. order 的 lines 已打乱。
7. **每道选择题逐题检查：四个选项无近义改写、无包含关系、无语义类别重复；干扰项看似合理但可辨析排除，不出现一眼假的凑数项；正确项不因表述最完整而露馅。**
8. 输出为纯 JSON。

现在只输出 exercise.json 内容。
